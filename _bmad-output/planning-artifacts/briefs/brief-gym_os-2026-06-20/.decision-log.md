## 2026-06-20 — Session 1 (continued)

- **Pricing model decided** — monthly and annual subscription per gym (not per-member, not per-transaction). Annual billing option included for commitment incentive. Transaction fees pass through to gyms. Specific price points and tier names deferred to pre-billing Epic.
- **Language** — bilingual English + French from V1. i18n library choice deferred to team. All strings externalized.
- **White-label branding** — logo + gym name + primary color only in V1. Applied at runtime per gym_id; one binary serves all gyms. Full theme system deferred to V4+.
- **Currency** — XAF in V1. Multi-currency column (`currency`) present from day one for expansion to NGN, GHS, and other African markets at V2+.
- **Gym onboarding** — GymOS-provided CSV template + dashboard import tool. Manual data entry by GymOS team for pilot gyms. Payment history not migrated; fresh start.
- **Notifications** — Expiring (7-day, 1-day), expired (same day), payment confirmed/failed in V1. Quiet-gym alerts and class reminders (60min before) in V1.5. All via Expo Push → FCM + APNs.
- **Scale targets** — ~30 members per gym at pilot launch; 1–3 gyms. Architecture designed to scale well beyond without rework.
- **Deployment** — Vercel (dashboard), Supabase Cloud (backend), EAS (mobile). Dokploy/VPS decision pending for V1.5.
- **Observability** — Sentry (errors, V1). PostHog deferred to V1.5. Supabase built-in for DB health.
- **Testing** — RLS tests + Notch Pay sandbox integration tests in CI. Manual Android QA pre-release. No E2E in V1; revisit at V1.5.
- **Timezone** — UTC stored everywhere. Africa/Douala default display. Gym timezone configurable field from V1 for multi-market readiness.
